VLOOKUP in Excel, Step by Step: Find a Price in a Table

Published November 18, 2026 · 8 min read

VLOOKUP finds a value in the first column of a table and brings back something from another column in the same row. It is the classic way to look up a price, a name or a category. Here it is, step by step.

What VLOOKUP does

You give it a code, and it returns the matching item from the table. The formula has four parts:

=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
  • lookup_value is what you are looking for, such as a product code.
  • table_array is the table where Excel will look. The value you search for must be in its first column.
  • col_index_num is the number of the column to return, counting from the first column of the table.
  • range_lookup is FALSE for an exact match, which is what you want almost every time.

An example with a price list

This price list is in A1:C4:

ABC
1CodeProductPrice
2A101Notebook4.50
3A102Pen box12.00
4A103Backpack39.90

In E2 you type a code, for example A103, and in F2 you want its price:

=VLOOKUP(E2,A2:C4,3,FALSE)
  1. Excel takes the code in E2 (A103).
  2. It searches for it in the first column of A2:C4, and finds it in row 4.
  3. It returns the value from the 3rd column of the table (Price), which is 39.90.
  4. FALSE tells Excel to accept only an exact match.

Why you need FALSE

If you leave the last part out, or write TRUE, Excel does an approximate match. That only works when the first column is sorted from smallest to largest, and otherwise it quietly returns a wrong answer. Write FALSE unless you are working with ranges such as tax brackets.

Lock the table with dollar signs

When you copy the formula down, the table reference would shift with it. Add dollar signs to keep it fixed:

=VLOOKUP(E2,$A$2:$C$4,3,FALSE)

When you see #N/A

#N/A means the value was not found. Look for a typo in the code, an extra space at the end, or a number stored as text. To show a friendly message instead of the error:

=IFERROR(VLOOKUP(E2,$A$2:$C$4,3,FALSE),"Not found")

The limits of VLOOKUP

  • It can only look to the right: the value you search for has to be in the first column.
  • The column number breaks if someone inserts a column inside the table.

Two alternatives fix this. XLOOKUP, available in Microsoft 365 and Excel 2021 and later, does the same job with separate ranges, for example =XLOOKUP(E2,A2:A4,C2:C4). And INDEX with MATCH works in every version.
