IF Function in Excel: Simple Examples That Make Sense

Published November 18, 2026 · 6 min read

The IF function lets a spreadsheet make a decision for you: if something is true, show one result, and if not, show another. Here is how it works, with examples you can copy.

How IF works

IF has three parts, separated by commas:

=IF(test, value_if_true, value_if_false)
  • test is a question Excel can answer with true or false, such as B2>=60.
  • value_if_true is what to show when the answer is true.
  • value_if_false is what to show when it is false.

Example 1: pass or fail

A teacher wants to mark every score of 60 or more as a pass. The scores are in column B, and the result goes in column C:

ABC
1StudentScoreResult
2Ana45Fail
3Ben72Pass
4Cy60Pass

In C2 type:

=IF(B2>=60,"Pass","Fail")

The test is B2>=60, which reads "B2 is greater than or equal to 60". Ana has 45, so the test is false and Excel shows Fail. Cy has exactly 60, and because of the >= that counts as a pass. Text results go between double quotes.

Example 2: calculate instead of showing text

The results of IF do not have to be words. A company pays a 10% bonus on sales above 10,000, and nothing otherwise. The sales are in column B:

=IF(B2>10000,B2*0.1,0)

With a sale of 12,000 the test is true, so Excel calculates 12,000 × 0.1 and shows 1,200. With a sale of 8,000 the test is false, so it shows 0. Copy the formula down the column and every row gets its own answer.

Example 3: compare text

To label each invoice as paid or open, based on the word in column C:

=IF(C2="Yes","Paid","Open")

Text in a formula always goes between quotes. IF does not care about capital letters, so "yes", "Yes" and "YES" all match.

Common mistakes

  • Forgetting the quotes around text. =IF(B2>=60,Pass,Fail) shows a #NAME? error, because Excel thinks Pass is a name.
  • Using > when you mean >=. With B2>60, a score of exactly 60 fails. Check the boundary values.
  • Leaving out the third part. If the test is false and you gave no value_if_false, Excel shows FALSE.
  • Commas versus semicolons. In some languages and regional settings, such as Portuguese and Spanish, Excel separates the parts with semicolons and the function has another name: =SE(B2>=60;"Aprovado";"Reprovado").

What to learn next

Once IF feels natural, combine several tests with AND and OR, and use IFS or nested IF when there are more than two outcomes.
